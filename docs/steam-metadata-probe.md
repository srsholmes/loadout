### Header layout discrimination

A section body opens with `0x00` and the section's last two bytes are `0x08 0x08`. A wrong header size lands mid-sha1 instead of on a type byte, so this measurement discriminates where the chain walk cannot.

**Header is 68 bytes** (picsToken + sha1_binary) — framed correctly for all 1247 sections. This is what Phase 3's `sections.ts` must use.
